# Health ERP client

Angular 22 standalone application with PrimeNG 22, Tailwind CSS, signals and reactive forms.

See the [project README](../README.md) for features, API configuration and local startup, [testing guide](../docs/testing.md) for validation, and [PrimeUI licensing notes](../docs/licensing.md) before using PrimeNG.

```powershell
npm.cmd ci
npm.cmd start
```

The development proxy sends /api and /hubs to the local backend. Never put server credentials in client code or bundles. Static illustrations use fictional demo data.
